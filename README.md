# デスク整理

Windows 向けの WPF デスクトップ整理アプリです。カテゴリーごとに独立した枠を表示するため、エクスプローラーや他のアプリを通常どおり前面で操作できます。アプリ起動中は項目の重複を避けるため エクスプローラーのデスクトップアイコンを一時的に非表示にし、終了時に元へ戻します。デスクトップ項目自体の位置やファイルは移動しません。

## v2.0.1

ランタイムをサポート中の .NET 10 に移行しました。公開バイナリは Authenticode 署名なしです。配布 ZIP、依存関係スキャン結果、SHA-256 は GitHub Releases で確認してください。

## v2.0.0

初回起動時に `ゲーム`、`ツール`、`SNS`、`エイメス` の4カテゴリーと既定の背景画像を作成します。既存の設定がある場合は維持されます。`your Aemeath` のトレイメニューからメインメニューやカテゴリーを操作でき、表示先モニターも選べます。Win+D でデスクトップを表示してもカテゴリーは残ります。v1.0.0 からの変更点は [RELEASE_NOTES_v2.0.0.md](RELEASE_NOTES_v2.0.0.md) を参照してください。

## ビルド

```powershell
dotnet build DeskSort.csproj -c Release
dotnet publish DeskSort.csproj -c Release -r win-x64 --self-contained false -o publish\win-x64
```

公開フォルダー内の `デスク整理.exe` を起動します。.NET 10 Windows Desktop Runtime が必要です。Release の実行ファイルや ZIP は Git に含めず、上記の `dotnet publish` で生成します。

## 設定とプロファイル

設定は `%LOCALAPPDATA%\DeskSort\profiles` にプロファイルごとに保存されます。初回起動時に旧 `%LOCALAPPDATA%\DeskSort\settings.json` があれば、既定プロファイルへコピーして引き継ぎます。上部の「◇」メニューから設定を切り替えたり、現在の設定を新しいプロファイルとして保存できます。

ファイルカードを別カテゴリーへドラッグすると分類を変更できます。カードを右クリックすると項目ごとの画像アイコンを設定・リセットできます。未設定のアプリやショートカットは Windows の既定アイコンを表示し、選択した画像アイコンは縮尺と表示位置を個別に調整できます。カテゴリーの `⠿` をドラッグすると位置を変更でき、矢印で展開・折りたたみできます。カテゴリーの背景画像は表示方式、拡大率、左右位置、上下位置を調整できます。

空のカテゴリーを趣味の画像展示に利用できます。カテゴリーの「背景画像を選択…」から画像を設定し、右下のハンドルで表示領域の幅と高さを調整してください。背景画像は高解像度で表示し、設定後は空カテゴリーの案内文を隠します。ログイン時の自動起動は上部のチェックボックスから切り替えられます。アクセントカラーは `#EB13C0` です。

上部メニューの「♫」ボタンから、独立したシステム音声ビジュアライザーを切り替えられます。Windows の既定の再生デバイスの音量ピークを読み取り、音声データを保存せずにバー表示へ反映します。モジュールはドラッグで移動、右下のハンドルでサイズ変更でき、位置とサイズはアプリの設定に保存されます。

カテゴリー設定の「画像フォルダーをスライドショー表示…」からフォルダーを選ぶと、画像を 5 秒ごとに切り替えます。画像は縦横比を保ったまま表示領域に自動で収めます。カテゴリー右下のハンドル、またはウィンドウの端をドラッグして表示領域のサイズを調整できます。フォルダーと領域サイズはアプリの設定に保存されます。

項目カードは複数列で表示し、項目が多いカテゴリーにはスクロールバーを表示します。
